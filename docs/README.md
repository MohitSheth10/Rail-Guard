# Documentation

This folder contains the detailed engineering side of Rail-Guard.

If you're new to the project, start with `01-concept.md`.

If you want to see what went wrong and how the design changed, read `PROBLEMS.md`.

| File | What's inside |
|---|---|
| [`01-concept.md`](01-concept.md) | Why I chose this problem and what already exists |
| [`02-design.md`](02-design.md) | How I designed the rail section, fishplate and sensor mounting |
| [`03-build.md`](03-build.md) | How the physical prototype was actually made |
| [`04-electronics.md`](04-electronics.md) | Components, wiring, pin map and electronics testing |
| [`05-software.md`](05-software.md) | ESP32 firmware, sampling and data collection |
| [`06-theory.md`](06-theory.md) | The rail calculations and natural-frequency analysis |
| [`PROBLEMS.md`](PROBLEMS.md) | The problems I ran into, in the order they happened |

The other READMEs in the repository explain the code, hardware, data and project records separately.

Start with [`01-concept.md`](01-concept.md) if you want the background, or [`PROBLEMS.md`](PROBLEMS.md) if you want the interesting parts.
